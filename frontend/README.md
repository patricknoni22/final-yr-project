# Student Lecturer Booking App

A student-lecturer booking application.

## Main Roles

- Student
- Lecturer

## Main Features

- Student and lecturer authentication
- Lecturer search and profile viewing
- Appointment booking
- Lecturer availability management
- Booking approval/rejection
- Notifications

## Stack

- React Native
- Expo
- Expo Router
- JavaScript / JSX
- TanStack Query
- Zustand
- Axios
- React Hook Form
- Zod or Yup
